# DerbyMax
derby timer software for engineering class

Start the program by running the server.py file within the derbyMax file.
Close the program by closing the linked webpage.

Core processing and data management is done in python, GUI hosted via a local webpage on http://127.0.0.1:5000 

Features:
-Time tracking from derby car ramp timer over USB (connect VIA the COM port selector).
-Profile creation and race time records + graphing.
-Heat scheduler and lane scrambler.
-Standing viewer with multiple statistics.
-Manual heat creation.
-Class data management using the built in .derby file creator and loader. 
-Heat records.
-Average lane speed tracker.
